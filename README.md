# Bella's Cowtent

A blog you write in your web browser. Nothing to install.

1. Sign in to [GitHub](https://github.com/login), or
   [make a free account](https://github.com/signup).
2. Click the button below. Leave everything as it is and click
   **Create codespace**.
3. When the editor asks whether you trust the authors of the files, click
   **Trust Folder & Continue**. It opens **01 Getting started**, which takes
   you from there.
